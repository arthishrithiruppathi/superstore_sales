Superstore Sales Analysis

A simple data analysis project using Pandas and NumPy on the Superstore sales dataset from Kaggle.

Files
main.py : the analysis code
sales.csv : the dataset (9,994 rows, 9 columns)
requirements.txt : required libraries
region_summary.csv : output file created by the code
What the Project Does
Loads and explores the CSV file
Cleans the data (checks missing values, removes duplicates, converts dates)
Adds new columns (Year, Month, Profit Margin %)
Calculates statistics using NumPy
Filters, sorts and groups the data
Finds business insights
Saves a regional summary
Results
Total sales: 2,296,914.56
Total profit: 286,408.34
Best region: West
Most profitable category: Technology
Least profitable sub-category: Tables

Tools Used

Python, Pandas, NumPy
